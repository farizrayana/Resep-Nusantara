# Resep Nusantara

Aplikasi katalog resep Flutter dengan data dari TheMealDB dan penyimpanan favorit lokal.

## Fitur
- Menjelajahi resep berdasarkan kategori.
- Mencari resep berdasarkan nama.
- Melihat detail resep, bahan, dan langkah memasak.
- Menyimpan dan menghapus resep favorit menggunakan SharedPreferences.
- Tampilan loading, error, dan data kosong.

## Menjalankan aplikasi
1. Pastikan Flutter SDK sudah terpasang.
2. Buka folder project ini di VS Code.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run` pada emulator atau perangkat.

Sumber data: [TheMealDB](https://www.themealdb.com/).
